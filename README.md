# ⛽ Пальне UA

Легкий та швидкий Android-застосунок для перегляду актуальних середніх цін на пальне по всіх областях України та миттєвого розрахунку вартості заправки.

## ✨ Основні можливості

* **Актуальні ціни з Мінфіну:** автоматичне завантаження даних (`index.minfin.com.ua`) із відображенням точної дати оновлення.
* **Усі області України:** зручний вибір регіону зі збереженням останнього вибору.
* **5 видів пального:** А-95 преміум, А-95, А-92, Дизпаливо (ДП) та Газ автомобільний.
* **Калькулятор заправки:** миттєвий розрахунок вартості обраної кількості літрів для потрібного пального.
* **Темна тема та оптимізація:** контрастний темно-графітовий інтерфейс із R8-стисненням без зайвої ваги (**2.69 МБ**).

## 📥 Завантажити додаток

👉 **[Завантажити FuelUA v1.1 (.apk)](https://github.com/Fastoft/FuelUA/releases/download/v1.1/fuelua-v1.1.apk)**

> **Примітка для встановлення:** під час першого запуску APK-файлу дозвольте браузеру або месенджеру встановлення додатків із невідомих джерел у налаштуваннях Android. Починаючи з версії `v1.1`, додаток підписаний офіційним ключем розробника, тому всі наступні оновлення ставитимуться поверх старої версії без її видалення.
