⛽ Пальне UA

Легкий та швидкий Android-застосунок для перегляду актуальних середніх цін на пальне по всіх областях України та миттєвого розрахунку вартості заправки.

## ✨ Основні можливості
* **Актуальні ціни з Мінфіну:** автоматичне завантаження даних (`index.minfin.com.ua`) із відображенням точної дати оновлення.
* **Усі області України:** зручний вибір регіону зі збереженням останнього вибору.
* **5 видів пального:** А-95 преміум, А-95, А-92, Дизпаливо (ДП) та Газ автомобільний.
* **Калькулятор заправки:** миттєвий розрахунок вартості обраної кількості літрів для потрібного пального.
* **Темна тема:** контрастний темно-графітовий інтерфейс без зайвої ваги (~6.6 МБ).
